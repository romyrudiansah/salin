# Salin: website dan unduhan

**Salin** adalah penyalin file freeware untuk Windows. Salin menyalin dan memindahkan file dengan antrean per
drive, jeda di tengah file, verifikasi hash, dan log. File setengah jadi tidak pernah memakai nama asli, dan
file sumber baru dihapus setelah salinannya lengkap. Gratis untuk rumah, kantor, dan sekolah.

- Website: https://romyrudiansah.github.io/salin/
- Unduh installer: https://romyrudiansah.github.io/salin/#unduh
- **Diskusi, tanya jawab, ide, laporan masalah:** tab [Discussions](https://github.com/romyrudiansah/salin/discussions)
- Kebijakan privasi: https://romyrudiansah.github.io/salin/privacy.html

Repo ini hanya berisi hasil build website, dan installernya ada di
[Releases](https://github.com/romyrudiansah/salin/releases). Salin adalah freeware dan kode sumbernya tidak
publik. Lisensinya ada di [LICENSE.txt](LICENSE.txt), dan komponen pihak ketiga ada di
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Isi repo ini ditimpa setiap rilis.

---

**Salin** is a freeware file copier for Windows: copy and move files with a per-drive queue, pause in the
middle of a file, hash verification, and a log. Free for home, office, and school use. This repository only
holds the built website, and the installer is under [Releases](https://github.com/romyrudiansah/salin/releases).
Salin's own source code is not public; third-party components are listed in
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Questions, ideas, and bug reports go to
[Discussions](https://github.com/romyrudiansah/salin/discussions).
