Kebijakan privasiPrivacy policy

Terakhir diperbarui: 14 November 2026Last updated: 14 November 2026

Salin adalah penyalin file untuk Windows. File yang Anda salin dan pindahkan tidak pernah meninggalkan komputer Anda, kecuali ke drive atau folder jaringan yang Anda pilih sendiri sebagai tujuan.Salin is a file copier for Windows. The files you copy and move never leave your computer, except to a drive or network folder that you choose as the destination.

Data yang disimpan aplikasiWhat the app stores

Salin menyimpan pengaturan (bahasa, tema, aturan konflik, verifikasi, bunyi, dan ukuran jendela), delapan folder tujuan terakhir, serta laporan galat di %APPDATA%\Salin di komputer Anda. Daftar file yang disalin hanya ada di memori selama Salin terbuka, kecuali Anda sendiri menyimpannya lewat "Simpan log". Uninstaller menawarkan untuk menghapus folder itu.Salin keeps its settings (language, theme, conflict rule, verification, sound, and window size), the last eight destination folders, and error reports in %APPDATA%\Salin on your computer. The list of copied files lives only in memory while Salin is open, unless you save it yourself with "Save log". The uninstaller offers to delete that folder.

Menu klik kanan Explorer dan pintasan "Kirim ke" ditulis untuk akun Windows Anda saja (HKCU), dan dilepas saat Salin dicopot atau dari Pengaturan.The Explorer right-click menu and the "Send to" shortcut are written for your Windows account only (HKCU), and removed when Salin is uninstalled or from Settings.

Sambungan internet aplikasiWhat the app connects to

Salin tidak mengirim file, nama file, atau data pemakaian ke mana pun. Satu-satunya sambungan keluar:Salin sends no files, no file names, and no usage data anywhere. Its only outgoing connection:

  • Sekali sehari untuk memeriksa versi baru, dengan meminta latest.json dari situs Salin di GitHub Pages. Tidak ada data Anda di dalam permintaan itu, dan pemeriksaan ini bisa dimatikan di Pengaturan. Installer baru diunduh dari GitHub hanya bila Anda setuju, lalu ukuran dan SHA-256-nya dicocokkan sebelum dijalankan.Once a day to check for a new version, by requesting latest.json from the Salin website on GitHub Pages. That request carries none of your data, and you can turn the check off in Settings. A new installer is downloaded from GitHub only if you agree, and its size and SHA-256 are checked before it runs.

Laporan galat ditulis hanya ke komputer Anda dan tidak dikirim ke mana pun. Anda sendiri yang memutuskan apakah menyalinnya ke Komunitas.Error reports are written only to your computer and are not sent anywhere. You decide whether to copy one to the Community.

Yang tidak kami lakukanWhat we do not do

  • Tidak ada analitik, telemetri, iklan, atau pelacakan.No analytics, telemetry, advertising, or tracking.
  • Tidak ada akun, dan tidak ada data yang dijual atau dibagikan.No accounts, and no data sold or shared.

Situs Salin juga tidak memakai cookie, analitik, atau sumber dari pihak lain. Pilihan bahasa dan tema Anda disimpan di browser Anda sendiri. Situs, unduhan, dan diskusi komunitas berada di GitHub (github.com/romyrudiansah/salin), yang bisa mencatat permintaan seperti kunjungan web biasa. Yang Anda tulis di diskusi bersifat publik dan mengikuti kebijakan privasi GitHub.The Salin website doesn't use cookies, analytics, or third-party resources either. Your language and theme choice are stored in your own browser. The website, downloads, and community discussions are hosted on GitHub (github.com/romyrudiansah/salin), which may log requests like any web visit. What you post in the discussions is public and covered by GitHub's privacy policy.
